## 环境缺口

### G-001：全站末页尚未实际跑到终点

- **缺失项**：当前站点总页数、最终空页的实时证据。
- **来源位置**：`/bookcity/get_filter_book_list`。
- **影响范围**：不影响分页实现，但不能宣称站点总书量。
- **获取建议**：正式任务使用 `crawl-all --yes`，保留 checkpoint 与速率限制，记录最终空页。

### G-002：LDPlayer proxy-off 上游脚本清理不完整

- **缺失项**：对 host、port、PAC、exclusion list 的统一删除和关闭后断言。
- **来源位置**：`D:/reverse_ENV/tools/ldplayer/ldplayer.ps1`。
- **影响范围**：从模板复制的新实例仍可能复发正文 CDN `ECONNREFUSED`。
- **获取建议**：在环境仓单独修复并清理 `re-xposed` 模板；不要在本项目仓混改。

## 待验证假设

### H-001：2.9.352 是 current response key 的精确版本门槛

- **假设**：版本 `>=2.9.352` 使用 current key，较早版本使用 legacy key。
- **依据**：2.9.328 真实响应可用 legacy key，2.9.352 / 2.9.362 进入 current 分支；Native 函数存在显式 mode 分支。
- **验证方法**：若要支持更多历史版，分别抓取 2.9.329–2.9.351 与 2.9.352 首版调用方传入的 mode。
- **若假设错误的影响**：仅影响少见历史版本自动选 key；当前 2.9.362 不受影响。
